# Sabores de Cuscatlán

Guía de gastronomía típica salvadoreña: recetas de platillos y bebidas tradicionales, lugares recomendados para comer y festivales gastronómicos de El Salvador.

🌐 **Sitio web:** https://saboresdecuscatlan.vercel.app/

> *Tu mapa de sabores, recetas y tradiciones en El Salvador.*

## Secciones

- **Platillos típicos:** pupusas, tamales, sopas y más, con historia, ingredientes, receta y video.
- **Bebidas y postres:** frescos, atoles y dulces tradicionales con su preparación.
- **Lugares recomendados:** restaurantes y comedores por zona, con enlaces a Google Maps y Waze.
- **Festivales gastronómicos:** ferias y festivales por departamento, con fechas y cómo llegar.
- **Contacto**

## Cómo ejecutarlo en local

```sh
npm install
npm run dev
```

El sitio se abre en `localhost:4321`. Para generar la versión de producción:

```sh
npm run build
```
